# Module 0: Getting Ready

This module gets your computer ready for the course. By the end of it you will have a working Linux command line, a package manager for installing bioinformatics tools, and the course data on your machine. Nothing here is bioinformatics yet — it is the setup that makes everything in later modules possible.

Do this module **before the first teaching session**, or at the very start of it. If you get stuck on any step, bring the exact error message to the session or send it to a facilitator — setup problems are common and quick to fix once we see the message.

## Two ways to take this course

You will use **one** of two environments throughout the course:

- **WSL (Windows Subsystem for Linux)** — a real Linux system running inside your own Windows computer. You install this once (Lesson 2).
- **TLJH (The Littlest JupyterHub)** — a shared Linux server the facilitators run. You use it through your web browser; there is nothing to install. Your facilitator will give you a web address, a username, and a password.

Every lesson in the course tells you what to do in each environment whenever the steps differ. If you are on TLJH, you can skip the WSL installation in Lesson 2.

## Learning objectives

By the end of this module, you will be able to:

- Explain what the Linux command line is and why bioinformatics relies on it
- Open a Linux terminal, either through WSL or TLJH
- Install a conda package manager (Miniforge) for installing bioinformatics tools
- Download and unpack the course `Training/` data
- Confirm your whole setup works with a short smoke test
